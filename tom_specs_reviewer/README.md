# tom_specs_reviewer

A Flutter tool for **reviewing the TomSpecs object model** (`tom_specs_model`).

It browses the exported spec model graph (`assets/spec_model.json`, generated by
`tom_specs_clitool/bin/model_json.dart`) as a tree and lets a reviewer record
structural observations — scope flags, "stop here" / "add details" markers, and
free-text comments — keyed by structural path. Those observations feed **further
development of the object model itself**.

It is *not* a specification editor. The editor that authors actual
specifications (DocSpecs / CodeSpecs / Implementation specs) is a separate app,
`tom_specs_editor`, in the `tom_forge` repo.

## Run

```bash
flutter pub get
flutter analyze
flutter test
flutter run        # or: flutter build bundle | web | linux | macos
```

The review file location can be overridden with the `TOM_SPECS_REVIEW_FILE`
environment variable (default: `<cwd>/review/structure_review.yaml`).
