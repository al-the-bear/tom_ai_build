# digits) but are not todo ids.
#
# Read by bin/check_todo_citations.dart. The checker recognises citations by
# *shape* rather than by an enumerated list of series, because an enumeration
# only ever knows the series someone remembered to add — the sweep that
# motivated the checker found eight citations of a series no enumeration
# contained. The price of a shape rule is that ordinary technical terms collide
# with it; this file is that price, paid one word at a time.
#
# Add a token here only when it is genuinely not a todo id. If a token *is* a
# todo id that the corpus cannot resolve, the fix is the citation or the corpus,
# never this file.
#
