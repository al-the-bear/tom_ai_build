Empty in this walkthrough, and legitimately so.

navigation routes, view state and client configuration. All derive from the
experience-design and interaction-scenario parts of a specification, and this
walkthrough carries neither — it stops at the information model and the
requirement that justifies the project.

The directory exists anyway: Phase 4 emits the trio whatever the specification
says (`codespecs_mapping.md` §4.2).
