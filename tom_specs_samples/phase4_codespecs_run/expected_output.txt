4. Validating the emitted trio                [MECHANICAL]
   `validate_codespecs.dart` runs the derivation contract's §6
   checks over the shared / client / server trio. It reads emitted
   Dart with the analyzer's parser and never resolves it, so it runs
   on a tree that has never been through `pub get` — which is what
   lets a generator validate its own output before anything fetches
   a dependency.

   Four questions cannot be answered from the trio alone, and each
   brings its own corroborating input. When one is absent the tool
   NAMES on stdout the checks it left unrun — so a skipped check
   never reads as a passed one. Below, recorded by tool/validate.sh,
   the same trio validated twice: once without the extracts and once
   with them.

   $ validate_codespecs --shared codespec/shared --client codespec/client \
                         --server codespec/server
     codespecs: check 13 (migration convergence) not run — pass --migrations pointing at the run's CE-MG artifacts.
     codespecs: check 9 (mirrored catalogues) not run — pass both --cs-vocabulary and --core-source; a catalogue neither side declares mirrors an empty one, which compares equal.
     codespecs: check 31 (determinism) not run — pass --regenerated-shared/--regenerated-client/--regenerated-server pointing at a second generation run over the same model.
     codespecs: check 19 (secret is declared), checks 32, 33 and 34 (comment source, template and fidelity) and checks 35 and 36 (extract coverage and back-link resolution) not run — pass --extracts pointing at the run's generated-doc/codespecs_extracts directory.
     codespecs: 37 checks passed

   $ validate_codespecs --shared codespec/shared --client codespec/client \
                         --server codespec/server \
                         --extracts build/codespecs_extracts
     codespecs: check 13 (migration convergence) not run — pass --migrations pointing at the run's CE-MG artifacts.
     codespecs: check 9 (mirrored catalogues) not run — pass both --cs-vocabulary and --core-source; a catalogue neither side declares mirrors an empty one, which compares equal.
     codespecs: check 31 (determinism) not run — pass --regenerated-shared/--regenerated-client/--regenerated-server pointing at a second generation run over the same model.
     codespecs: 37 checks passed

   Supplying --extracts moved six checks from "not run" to "ran".
   That is the whole reason the extract is an artifact of record and
   not a transient buffer: it is the only place the specification's
   own sentences survive, and checks 32-34 hold every emitted doc
   comment against them. No reading of the code alone can tell a
   copied sentence from a composed one.
